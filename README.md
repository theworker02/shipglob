# shipglob

Ship and reshape glob text streams with deterministic transforms.

**Site:** https://theworker02.github.io/shipglob/

## Install / run

```bash
git clone https://github.com/theworker02/shipglob.git
cd shipglob
node src/cli.js
node --test
```
